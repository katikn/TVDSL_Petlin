# HW03 Semantic Analysis & Type Checking

## 1. Выполненные требования

| Критерий | Реализация |
|---|---|
| **Таблицы символов** | Иерархический `Scope` с поддержкой областей видимости функций, блоков `{ ... }` и кванторов. Проверка повторных объявлений и видимости до объявления. |
| **Проверка типов** | Типизация выражений, ветвлений (`if`), циклов (`while`), проверок (`assert`/`assume`), контрактов (`requires`/`ensures`) и вызовов функций (число и типы аргументов). |
| **Диагностика** | Локализация `[line:col]`, информативные сообщения, сбор всех ошибок без ранней остановки. |
| **Тесты и документация** | Тестовый набор `test_types.py` (позитивные и негативные сценарии), `README.md` и `REPORT.md`. |
| **Вывод типов** | Переменные без аннотации типизируются по первому присваиванию (`is_inferred = True`) с контролем типов при последующих записях. |

---

## 2. Ключевые решения

1. **Иерархический Scope:** Поиск имен (`lookup`) идет от внутреннего блока к глобальному уровню, обеспечивая корректное затенение (shadowing) переменных.
2. **Двухпроходный анализ:** На первом проходе собираются сигнатуры всех функций, на втором — проверяются тела. Это обеспечивает взаимную рекурсию и вызовы функций независимо от порядка их описания.
3. **Аннотированный AST:** Каждое выражение сохраняет вычисленный тип в атрибуте `inferred_type`, который сериализуется в JSON для последующих этапов компиляции (T1/IR).
4. **Гашение каскадных ошибок:** Узлы с ошибкой получают служебный тип `"error"`, что исключает лавину ложных сообщений в родительских выражениях.

## 3. Система типов

- **Типы:** `int`, `bool`, `int[]` (массивы с операцией `length(arr)` и сахаром обновления `arr[i] = v;`).
- **Операции:** 
  - Арифметика (`+`, `-`, `*`, `/`): `(int, int) -> int`
  - Сравнения (`<`, `<=`, `>`, `>=`): `(int, int) -> bool`
  - Равенство (`==`, `!=`): `(T, T) -> bool`
  - Логика (`and`, `or`, `->`, `not`): строго `bool`
- **Контракты и условия:** `if`, `while`, `invariant`, `requires`, `ensures`, `assert`, `assume` требуют тип `bool`.
